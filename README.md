## 汉化了什么

- **书本、信件、日记、报纸**：46 篇文档全部重译
- **菜单、道具描述、屏幕提示**：388 条消息全部重译
- **片头动画**：整段重制，30 条中文字幕（跟中文配音的时间线走）
- **画面里的字**：标题「鬼屋魔影3」、开场的办公室与日期、章节卡「第二天」、物件名与界面
- **排版**：GB2312 点阵字库，行距加宽，汉字不挤行
- **中文配音（可选）**：71 段，见下方「语音包」

**保留原文**：制作人员名单卡仍是原版素材，没有改动。

**翻译底本**：以英文版文本为底本重译，术语沿用本系列前两作汉化的定译；与法文原意冲突处，以法文为准。

## 安装

1. 解压到**任意位置**：游戏根目录、子文件夹、甚至完全无关的路径都行。
2. 双击 `安装_文字.bat`。脚本会自己找游戏目录（也可以把游戏目录拖到它图标上），  
   确认前会显示找到的是哪一个。
3. 想要中文配音，再双击 `安装_语音.bat`。
4. 装完双击游戏根目录里的 `启动中文版.bat` 开始玩。

装的时候脚本会先核对原版文件，对不上会明确报错并中止，不会写出半成品。  
如果你的是光盘版、硬盘拷贝或自己拼的目录，看下面的「手动安装」。

## 启动

| 版本  | 怎么启动                              |
| --- | --------------------------------- |
| 中文版 | 游戏根目录 `启动中文版.bat`                 |
| 英文版 | 照旧（Steam 开始游戏 / GOG 的 DOSBox 启动器） |

装了配音包时，中文版启动会问一句：`1` 中文配音 / `2` 英文原声（15 秒不选默认中文）。  
没装配音包就直接英文原声，不弹菜单。两版共用同一批存档，互不影响。

## 语音包（可选）

装后中文配音，共 71 段：39 条 CD 朗读音轨（片头 + 书页、信件、日记、报纸）  
和 32 段游戏内语音（敌人招呼、受伤、喊话、短句对白）。

- 中文配音由 AI 语音合成后逐句后期，个别句子语气与英文原声不完全一致，属正常。
- 中文比英文长，朗读时长按「向上取整 + 1 秒静音」放宽，极少数段落会比英文版略长。
- 原版音轨只读，中英文配音随时切换，不用重装。

## 手动安装（光盘版 / 非标准目录）

游戏不在 Steam / GOG 的标准位置、或者自动找不到时，把**含 `INDARK3` 的那一层目录**拖到脚本图标上即可。  
如果那个目录缺 DOSBox 或光盘数据，脚本会先警告：答 `Y` 就只装汉化文件、不铺启动器，  
这时要自己配 DOSBox：

```
mount  C "游戏目录"
imgmount D "游戏目录\game.ins" -t iso
C:   然后  CD INDARK3   然后  AITD3CHS
```

装了语音包，第二行换成 `imgmount D "游戏目录\GAME_ZH.INS" -t iso`（挂错还是英文语音）。

## 卸载

安装时会把卸载脚本复制到游戏根目录，**直接去游戏目录双击就行**，不必找回压缩包：

- `卸载_语音.bat`：只删中文配音，文字汉化保留，启动器随即退回英文原声
- `卸载_文字.bat`：只删汉化新增的文件，原版和存档都不碰

建议先卸语音、再卸文字。反着卸也只是留下几个孤立文件，仍能清掉。

## 已知情况

- **片头字幕按中文配音的时间线排**，选「英文原声」时个别字幕可能与语音不完全同步。
- 制作人员名单卡、标题卡的像素美术字仍是原版素材。
- 存档槽名显示「加州 / 蒙大拿 / 内华达 / 俄州」——这是原版槽位名（美国州名），不是译错。
- 只支持英文版：法 / 德 / 西 / 意 / 日 / 葡语版的文件被重新编译过，字节不同，套不上本补丁。
- 在 Steam 里「验证文件完整性」可能清掉补丁，重新运行安装脚本即可。
